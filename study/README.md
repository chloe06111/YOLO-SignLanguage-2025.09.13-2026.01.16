# Unity 학습 기록

이 폴더는 완성 게임의 포트폴리오와 학습·참고 자료를 구분하기 위해 만들었습니다.

- `unity-practice/chp2-practice`: 로컬 `chp2 prac/My project`.
- `unity-practice/main-project`: 로컬 `MainProject/MainProject`.
- `unity-practice/top-view`: 로컬 `TopView`.
- `textbook-reference`: 외부 교재 예제 기반의 프로젝트 11개. 원저작자와 학습자의 기여를 혼동하지 않도록 [출처 안내](../docs/ATTRIBUTION.md)를 확인하세요.

각 프로젝트의 Assets, Packages, ProjectSettings를 보관하며, Library·IDE 캐시·macOS 보조 파일은 제외했습니다. 각 프로젝트의 Unity 버전은 해당 ProjectSettings/ProjectVersion.txt에서 확인할 수 있습니다.

# 출처와 사용 범위

## Team YOLO / SignPlay

SignPlay는 팀 프로젝트입니다. 퀴즈 씬 및 모델 연동에 대한 저장소 소유자의 기여와, 팀원이 제공한 모델·게임 전체 자산을 구분합니다. 상세 역할은 [CONTRIBUTIONS.md](CONTRIBUTIONS.md)를 참고하세요.

## 교재 기반 학습 자료

`study/textbook-reference`는 로컬 `교제연습/unity2d_jpub`에서 가져온 학습 스냅샷입니다. 로컬 Git 원격 주소는 **https://github.com/junyun0516/unity2d.git**, 확인한 로컬 HEAD는 `e9a01f76d595bfe37faa0bab18ccfb33c2278ca3`입니다. 원격 주소는 확인 당시 API 404로 응답해 현재 공개 접근 가능 여부를 확인하지 못했습니다.

이 폴더의 코드를 개인의 독자 창작이나 팀 게임의 구현 성과로 주장하지 않습니다. 원본 대비 개인 변경 범위도 이번 정리에서 확정하지 않았습니다. 교재·예제의 원저작권은 원저작자에게 있습니다.

## 폰트·음악·이미지·패키지

Unity 원본에는 폰트·음악·이미지·TextMesh Pro 등 외부 자산이 포함될 수 있습니다. 기존에 포함된 고지 파일은 보존했습니다. 각 자산의 출처와 재배포 조건을 이번 작업에서 모두 확인한 것은 아닙니다. 파일 보유 및 아카이브 사실이 외부 자산의 권리 소유를 뜻하지 않습니다.

루트의 기존 `LICENSE` 파일은 유지했습니다. 해당 파일만으로 팀원 또는 외부 자산 전체에 새 라이선스를 부여했다고 해석해서는 안 됩니다. 각 권리자의 조건과 별도 고지가 우선합니다.
